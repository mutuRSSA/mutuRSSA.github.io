Impor Data Mutu dari Google Sheet

Unggah file .xlsx hasil unduhan Google Sheet (File → Download → Microsoft Excel). Data diperiksa dulu sebelum disimpan.

1 Pilih file
Klik atau seret file ke sini
File unit (DB_MUTU_*.xlsx) — boleh banyak sekaligus. Sertakan juga DATABASE_MUTU_MASTER.xlsx untuk mencocokkan angka dengan rekap lama.
2 Periksa hasil pembacaan

Pastikan setiap file dipasangkan ke unit yang benar. Kombinasi unit + indikator + bulan yang sudah ada di aplikasi akan dilewati.

FileUnit tujuanSheet → Formulir (siap / sudah ada / bermasalah)Total file
3 Cocokkan capaian dengan rekap lama

Capaian dihitung ulang dengan rumus di Profil Indikator (aplikasi baru), lalu dibandingkan dengan REKAP_GABUNGAN di Google Sheet. Selisih biasanya berarti template rumus di Profil Indikator perlu dicek.

4 Impor ke database

Impor berjalan per batch. Jika terputus, cukup jalankan lagi: data yang sudah masuk otomatis dilewati.
