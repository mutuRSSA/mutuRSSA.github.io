Konversi Rumus Indikator Lama

Mengubah rumus COUNTIFS/SUMIFS di sheet Setup_Indikator (Google Sheet) menjadi template rumus aplikasi baru, lalu mengujinya dengan data di database sebelum disimpan ke Profil Indikator.

1 Pilih file DATABASE_MUTU_MASTER.xlsx
Klik atau seret file ke sini
Dibutuhkan sheet Setup_Indikator dan Setup_Formulir. Sheet REKAP_GABUNGAN (jika ada) dipakai untuk membandingkan hasil uji.
2 Periksa, uji, lalu terapkan

Kriteria bulan/tanggal dibuang karena data aplikasi baru sudah dikelompokkan per bulan. Kolom dicocokkan lewat judul kolom di Form Builder. Rumus gabungan (+/−), rujukan ke sheet lain, dan angka tetap ikut dikonversi. Indikator yang tidak punya Profil (mis. surveilans PPI) tidak ditampilkan di daftar utama karena tidak dilaporkan. Klik Uji untuk menghitung dengan data di database dan membandingkannya dengan rekap lama.
